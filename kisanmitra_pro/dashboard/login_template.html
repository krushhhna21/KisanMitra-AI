Under The Hood

How KisanMitra AI Works

Every query a farmer sends passes through a 6-stage intelligent pipeline — from raw input to precision advice — in under 3 seconds.

🌾
01

Farmer Input

Text, voice, or photo via Telegram in Hindi / Marathi / English

🔍
02

Intent Detection

Rule-based NLU classifies intent: pest / weather / mandi / crop / scheme

🧠
03

Context Fusion

Farmer profile + soil NPK + live weather + GPS location merged into prompt

⚡
04

LLM / Vision AI

Groq Llama 4 Scout generates or Llama Vision diagnoses from photo (sub-second)

🗄️
05

DB Logging

Response + intent + pest report stored in PostgreSQL for community outbreak tracking

📱
06

Farmer Reply

Personalized voice-native advice delivered to Telegram in farmer's own language

Input Layer
Multi-modal Raw Input
  • 📸 JPEG Photo → Base64 encoded for Vision model
  • 🗣️ OGG voice → Groq Whisper transcription → text
  • 💬 Text message → direct UTF-8 string
  • 📍 GPS coordinates → OpenStreetMap reverse geocode → location name
Processing Core
Context-Aware AI Engine
  • 🌾 Field data: area, crop type, soil type, village
  • 🧪 Soil NPK: pH, N, P, K, organic matter, EC injected into prompt
  • 🌦️ Live weather API overlaid on farmer's GPS location
  • 📜 Last 5 chat turns fetched from DB for session continuity
Community Safety
Pest Outbreak Broadcast
  • 🐛 Pest detected in photo → auto-logged in pest_reports
  • 🔔 If 3+ unique farmers in same location report same pest → ALERT triggered
  • 📢 AI generates emergency advisory with pesticide dosage
  • 🌐 Pushed to all opted-in farmers in that area via Telegram bot
⚡ Average end-to-end response time: < 3 seconds from input to Telegram reply
